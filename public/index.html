Container Registry MigrationWeOwn · 2026
Python · Docker · Harbor · DOCR

Migrating a container registry before the lights go out

Problem. The team's container registry (reg.mini.dev) announced shutdown with a hard deadline. 46 deployments across 3 accounts referenced images that would stop pulling in two weeks.

Built. Audited all 46 deployments, identified 7 unique images to mirror, and built registry-rollover.py — a Python script that re-tags and pushes images to DOCR and Harbor, updates deployment configs, and validates the rollover. Handled edge cases: 3 stale image tags that no longer existed, a private rescued image archive, and one blocked image (vendor rebrand). PR merged with tombstone markers for decommissioned references.

12 of 13 live deployments rolled over mechanically. Zero downtime.

OpenBao Secrets Automationbao.weown.tools · 2026
OpenBao · Bash · OpenRouter API

Automating API key rotation with an open-source Vault fork

Problem. API keys were rotated manually every time they expired — the CEO was doing it himself. No audit trail, no automation, no scoped access.

Built. provision-openrouter-key.sh — a Bash script that provisions budget-capped API keys via the OpenRouter API and stores them in OpenBao (open-source HashiCorp Vault fork). Supports manual paste and fully automated modes with configurable credit limits. Tested against production tenants with rollback verification. Integrated into the existing deployment pipeline with a per-instance SECRET_BACKEND flag flip — no script rewrite needed to migrate a tenant from Infisical to OpenBao.

Key rotation went from a manual CEO task to a single command with audit logging.

WordPress V5 MigrationWeOwn · 2026
OpenTofu · Bash · Caddy · UpdraftPlus

Migrating 6 WordPress sites with a reusable IaC pipeline

Problem. Six WordPress sites ran on legacy infrastructure with no automation, no version pinning, and no documented migration path.

Built. A config-driven migration system — wordpress-v5-migrate.sh reads a YAML config, provisions v5 droplets via OpenTofu, sets up Docker + Caddy for automatic TLS, restores content via UpdraftPlus, runs wp-cli search-replace for URL migration, and documents before/after baselines. Remote Terraform state on DigitalOcean Spaces with locking. Migrated burnedout.xyz, weown.academy, weown.bio, and burnedoutadvisor.com with zero data loss.

What used to be a manual weekend project per site now runs from a single YAML file.
